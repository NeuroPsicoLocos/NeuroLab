# Internacionalización de Simu-LAB

Simu-LAB ofrece español (`es`) e inglés (`en`) mediante una capa compartida en `shared/i18n.js`.
La traducción no duplica páginas ni modifica las claves científicas de los resultados.

## Reglas

- Español es el idioma inicial y el fallback cuando una clave no existe.
- `?lang=en` y `?lang=es` permiten compartir una vista en un idioma determinado.
- La preferencia se conserva localmente en el navegador.
- Los textos estáticos usan `data-i18n`; los mensajes calculados usan `i18n.t()`.
- Los nombres de esquemas, códigos de control de calidad, unidades, enums y columnas exportadas permanecen estables.
- Las traducciones funcionan en GitHub Pages, servidores estáticos y apertura directa mediante `file://`; no usan `fetch`.

## Alcance actual

El portal, PSP Lab y Electrophysiology Lab están traducidos. En el analizador, el idioma afecta únicamente la
interfaz: los nombres originales de hojas y columnas, códigos de control de calidad, esquemas, decisiones guardadas
y claves de exportación permanecen estables para conservar la trazabilidad entre idiomas.

## Añadir una traducción

1. Crear la misma clave en los diccionarios `es` y `en`.
2. Aplicar la clave con `data-i18n`, `data-i18n-aria-label`, `data-i18n-placeholder` o `data-i18n-content`.
3. Para texto dinámico, usar `i18n.t("clave", { parametro: valor })`.
4. Ejecutar las pruebas y comprobar que no aparece la clave literal en la interfaz.

Las traducciones científicas deben revisarse como terminología técnica, no solo como equivalencias literales.
