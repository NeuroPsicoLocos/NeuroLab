# NeuroGénesis · integración NeuroLab

Copia del atlas de desarrollo embrionario creado para Héctor Romo-Parra, integrada por autorización del propietario el 12 de noviembre de 2026. El Site original permanece intacto y privado.

## Procedencia y alcance de publicación
Fuente: versión 2 del proyecto NeuroGénesis, commit `ac792b636ad928fba360f2eb035c8f9bf94c9d55`. HTML, JS, CSS e imágenes locales provienen de esa fuente. El README de origen identifica tres ilustraciones didácticas originales y describe la base en la presentación proporcionada por el propietario. Se conservan bibliografía, avisos de simplificación y créditos existentes. No se presentan imágenes artísticas como datos histológicos.

Esta publicación no concede una nueva licencia sobre el contenido importado ni convierte en MIT los recursos editoriales. La autorización cubre publicar esta copia para acceso libre en NeuroLab. Referencias enlazadas y videos de YouTube pertenecen a sus respectivos titulares; no se descargan ni redistribuyen esos videos. Los videos solo se cargan mediante YouTube en respuesta a la acción del visitante.

## Cambios de integración
- Ruta local `/apps/neurogenesis/` y regreso a `../../#aprender`.
- Tarjeta del catálogo con traducciones ES/EN; contenido del atlas en español.
- Sin backend, cuentas, formularios externos ni datos de personas. Preferencias y último resultado se guardan en localStorage del navegador.
