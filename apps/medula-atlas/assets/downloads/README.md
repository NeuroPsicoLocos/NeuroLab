# Encéfalo desmontable

El paquete `encefalo-desmontable.zip` procede del proyecto local `Documents/3D printer`.

Contiene seis STL, seis OBJ, dos scripts Python de generación, el README original y un manifiesto de hashes. Se conservaron los archivos sin modificaciones. Las fotografías del proyecto no se incluyen.

Las geometrías son aproximaciones docentes basadas en un objeto didáctico. El README original explica sus límites, parámetros y medidas necesarias para probar el ensamblaje. Esta descarga no establece precisión anatómica o ajuste físico validado.
